# Abasthan Free - 合法领取部署包

用途：合规 Web 应用（小站 / API / Bot webhook），不是 VPN/代理。

## Abasthan 侧设置
- Service type: Web Service
- Runtime: Node.js 20
- Plan: Free (首个应用 $0)
- Start command: npm start
- Port: 平台自动注入 PORT，本代码已适配

## 本地推送到 GitHub
1. 在 GitHub 新建空仓库，如 abasthan-starter（账号 Timoncc）
2. 把本文件夹所有文件推到仓库 main 分支
3. 回 Abasthan Dashboard 连这个仓库部署
